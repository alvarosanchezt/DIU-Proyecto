# Proyecto
Admisión USM surge de la necesidad de estudiantes, próximos a egresar de educación media, de acceder de manera rápida e intuitiva a información clave para decidir si quieren ingresar a la USM.

## Tecnologias usadas en este proyecto:

Amisión USM esta construida con:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Requisitos 
* Instalar Node.js desde https://nodejs.org
* Después de instalarlo, reiniciar tu terminal
* Ejecutar npm install en la carpeta del proyecto

```sh
# Clonar el proyecto.
git clone <YOUR_GIT_URL>

# Instalar dependencias.
npm install

# Para previsualizar tus cambios en modo desarrollo.
npm run dev
```
